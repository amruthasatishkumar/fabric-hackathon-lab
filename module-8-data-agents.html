Ground a Fabric Data Agent on the Ontology

The final step turns your ontology into a conversation. Ground the Property Assessment Agent on PropertyAssessmentOntology as its only data source, so the evaluation proves that entity and relationship grounding works - answers become graph traversals, not table joins.

Learning Objectives

  • Create the Property Assessment Agent and add PropertyAssessmentOntology as its only source.
  • Apply the repo's grounding instructions, including the preview GQL guidance and AI-safety rules.
  • Evaluate the agent with relationship-aware questions and compare answers with the Gold tables.

Step 1 - Create & Ground the Agent DATA AGENT

⬇ Download notebook 5

  1. Add the ontology as the only source

    Create or open Property Assessment Agent, select Add a data source, and add PropertyAssessmentOntology. Use the ontology as the agent's only source for this exercise so the evaluation proves entity and relationship grounding works.

  2. Add grounding instructions

    Add Support group by in GQL to the instructions - the current Microsoft-documented preview guidance for improving ontology aggregations. Retain the synthetic-data, measure-definition, and AI-safety instructions from notebook 5:

    Instructions 
    You are the Sudsberry property assessment assistant. Answer only from the
PropertyAssessmentOntology by reasoning through its entities and relationships.

## Grounding
- Support group by in GQL.
- Traverse locatedIn, recordsFor, submittedFor, and occursIn to relate
  properties, neighbourhoods, comparable sales, and appeals.

## Rules and safety
1. State that all values and taxes are synthetic.
2. Distinguish assessed value from sale price - never conflate them.
3. Do not present AI sentiment as an appeal decision; it is decision support.
4. Say clearly when a question cannot be answered from the available data.

Step 2 - Test Relationship-Aware Questions

In the agent canvas, run the evaluation questions and confirm the agent traverses the graph:

  1. Which properties have both a comparable sale and an appeal?
  2. Show appeals for properties whose assessment-to-sale ratio is above 1.1.
  3. Which neighbourhood has the highest negative appeal sentiment rate?
  4. For a selected parcel, show its neighbourhood, comparable sales, and appeals.
  5. Which appealed properties also require inspection follow-up?
✓
Compare numeric results with the Gold tables and inspect the generated grounding. Do not accept an answer solely because it sounds plausible.

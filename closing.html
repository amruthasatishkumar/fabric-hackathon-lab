Traceable, Reusable, Responsible

✓
One traceable story. You can select a neighbourhood, spot a valuation or comparable-sales pattern, inspect its appeal themes, and explain the answer through the report or the agent - showing the source keys and transformations behind it.
💡
The reusability dividend. Onboarding another municipality doesn't require new code - connect their SQL, Cosmos, and ADLS sources, run the same notebooks, and reuse the ontology and agent. The bindings change; the pattern stays.
⚠
Responsible use. All data is synthetic. Values, taxes, and AI outputs are analytical demonstrations only and must not be used for real property valuation, taxation, or appeal decisions.

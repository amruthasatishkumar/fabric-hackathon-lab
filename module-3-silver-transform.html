Build the Silver Layer

Bronze holds the raw source shapes; Silver makes them analytics-ready. Three notebooks conform the mirrored SQL tables into typed dimensions and facts, flatten the Cosmos property documents, explode the nested inspection arrays, and ingest the ADLS appeals - writing managed Delta into a dedicated SilverLakehouse.

Learning Objectives

  • Create a SilverLakehouse and read the Bronze mirrors and shortcut cross-Lakehouse.
  • Conform casing and types for the shared keys (parcelId, neighborhoodId, taxYear, propertyClassCode).
  • Re-derive assessed_value (land + improvement) that mirroring may omit.
  • Flatten Cosmos property documents (including longitude/latitude) and explode the inspections[] array.
  • Ingest the ADLS appeals into a typed fact_appeal (AI enrichment follows in Goal 3).

Set Up the Silver Lakehouse & Notebooks

  1. Create SilverLakehouse with schemas enabled

    Click + New item → Lakehouse → name it SilverLakehouse and enable Lakehouse schemas so tables land in the dbo schema.

  2. Import the three Silver notebooks

    Import 1 - SQL Assessment to Silver, 2 - Cosmos Property Profiles to Silver, and 3 - ADLS Appeals to Silver and AI. Each notebook exposes logical Fabric item names in a parameter cell near the top - set them to the names you recorded in Goal 1. Attach SilverLakehouse as the default and add BronzeLakehouse as a source. In this goal you run notebook 3's ingestion cells only; its AI cells run in Goal 3.

Notebook 1 - SQL Assessment to Silver

  1. Conform every mirrored SQL table into Silver

    Snake-case every column, trim strings, enforce the business keys, and write one managed Delta table per source. The Assessment table re-derives assessed_value (mirroring may drop the computed column), and TaxRate becomes fact_tax_rate keeping its municipal_rate, regional_rate, and education_rate components (Gold combines them):

    PySpark 
    import re
from pyspark.sql import functions as F
from pyspark.sql.types import StringType

def snake_case(name):
    name = re.sub(r"(?<=[a-z0-9])(?=[A-Z])", "_", name)
    return name.replace(" ", "_").lower()

# source SQL table -> (Silver table, business keys that must be unique)
table_map = {
    "Jurisdiction":  ("dim_jurisdiction",   ["JurisdictionId"]),
    "Neighborhood":  ("dim_neighborhood",   ["NeighborhoodId"]),
    "PropertyClass": ("dim_property_class", ["PropertyClassCode"]),
    "Parcel":        ("dim_parcel",         ["ParcelId"]),
    "Building":      ("dim_building",        ["BuildingId"]),
    "Assessment":    ("fact_assessment",     ["ParcelId", "TaxYear"]),
    "Sale":          ("fact_sale",           ["SaleId"]),
    "TaxRate":       ("fact_tax_rate",       ["TaxYear", "PropertyClassCode"]),
}

for source_table, (target_table, source_keys) in table_map.items():
    frame = spark.read.table(f"BronzeLakehouse.{source_table}")
    for column in frame.columns:                       # snake_case every column
        frame = frame.withColumnRenamed(column, snake_case(column))
    for field in frame.schema.fields:                  # trim string columns
        if isinstance(field.dataType, StringType):
            frame = frame.withColumn(field.name, F.trim(F.col(field.name)))
    if target_table == "fact_assessment":              # re-derive computed column
        frame = frame.withColumn("assessed_value", F.col("land_value") + F.col("improvement_value"))
    keys = [snake_case(k) for k in source_keys]
    frame = frame.dropna(subset=keys).dropDuplicates(keys)
    (frame.write.format("delta").mode("overwrite")
          .option("overwriteSchema", "true").saveAsTable(target_table))
    print(target_table, frame.count(), "rows")
    ⓘ
    Keeping the three rate components in fact_tax_rate (rather than a pre-summed rate) lets Gold compute combined_rate and estimated_tax transparently.

Notebook 2 - Cosmos Property Profiles to Silver

  1. Flatten the property document

    Read the mirrored Cosmos properties container and flatten the nested jurisdiction, location, site, building, and currentAssessment objects into one row per parcel. The GeoJSON coordinates array is longitude first, then latitude:

    PySpark 
    raw = spark.read.table("BronzeLakehouse.properties")

property_profile = (
    raw
    .withColumn("parcel_id",               F.col("parcelId"))
    .withColumn("document_type",           F.col("documentType"))
    .withColumn("synthetic",               F.col("synthetic").cast("boolean"))
    .withColumn("neighborhood_id",         F.col("neighborhoodId"))
    .withColumn("neighborhood_name",       F.col("neighborhoodName"))
    .withColumn("country_code",            F.col("jurisdiction.countryCode"))
    .withColumn("region_code",             F.col("jurisdiction.regionCode"))
    .withColumn("currency_code",           F.col("jurisdiction.currencyCode"))
    .withColumn("longitude",               F.col("location.coordinates")[0].cast("double"))  # GeoJSON: longitude first
    .withColumn("latitude",                F.col("location.coordinates")[1].cast("double"))
    .withColumn("synthetic_address",       F.col("site.syntheticAddress"))
    .withColumn("property_class_code",     F.col("site.propertyClassCode"))
    .withColumn("zoning_code",             F.col("site.zoningCode"))
    .withColumn("lot_area_square_metres",  F.col("site.lotAreaSquareMetres").cast("double"))
    .withColumn("building_type",           F.col("building.type"))
    .withColumn("year_built",              F.col("building.yearBuilt").cast("int"))
    .withColumn("floor_area_square_metres",F.col("building.floorAreaSquareMetres").cast("double"))
    .withColumn("building_condition",      F.col("building.condition"))
    .withColumn("current_tax_year",        F.col("currentAssessment.taxYear").cast("int"))
    .withColumn("current_assessed_value",  F.col("currentAssessment.assessedValue").cast("double"))
    .withColumn("confidence_score",        F.col("currentAssessment.confidenceScore").cast("double"))
    .select("parcel_id", "document_type", "synthetic", "neighborhood_id", "neighborhood_name",
            "country_code", "region_code", "currency_code", "longitude", "latitude",
            "synthetic_address", "property_class_code", "zoning_code", "lot_area_square_metres",
            "building_type", "year_built", "floor_area_square_metres", "building_condition",
            "current_tax_year", "current_assessed_value", "confidence_score")
    .dropna(subset=["parcel_id", "neighborhood_id"])
    .dropDuplicates(["parcel_id"])
)
(property_profile.write.format("delta").mode("overwrite")
    .option("overwriteSchema", "true").saveAsTable("property_profile"))

  2. Explode the inspections array

    Each profile carries an inspections[] array. Use explode_outer so parcels without inspections are retained, and keep the observations array:

    PySpark 
    fact_inspection = (
    raw
    .withColumn("parcel_id", F.col("parcelId"))
    .withColumn("inspection", F.explode_outer("inspections"))
    .select(
        "parcel_id",
        F.col("inspection.inspectionId").alias("inspection_id"),
        F.col("inspection.inspectionDate").cast("date").alias("inspection_date"),
        F.col("inspection.inspectionType").alias("inspection_type"),
        F.col("inspection.condition").alias("condition"),
        F.col("inspection.observations").alias("observations"),
        F.col("inspection.followUpRequired").cast("boolean").alias("follow_up_required"),
    )
    .dropna(subset=["parcel_id", "inspection_id"])
    .dropDuplicates(["inspection_id"])
)
(fact_inspection.write.format("delta").mode("overwrite")
    .option("overwriteSchema", "true").saveAsTable("fact_inspection"))
print("fact_inspection:", fact_inspection.count(), "rows")
    ⓘ
    explode_outer turns one document with an array of inspections into tidy rows - the shape a star-schema join and a semantic model expect.

Notebook 3 - ADLS Appeals to Silver (ingestion)

  1. Conform the appeals into fact_appeal

    Import 3 - ADLS Appeals to Silver and AI and run its ingestion cells now - the AI cells run in Goal 3. Read the Parquet from the Bronze appeals shortcut, snake-case and type the columns, keep the raw narrative and ground_truth_sentiment, and write fact_appeal:

    PySpark 
    raw = spark.read.parquet("Files/appeals/assessment_appeals.parquet")  # BronzeLakehouse shortcut
for column in raw.columns:
    raw = raw.withColumnRenamed(column, snake_case(column))

fact_appeal = (
    raw
    .withColumn("tax_year",                 F.col("tax_year").cast("int"))
    .withColumn("submitted_date",           F.to_date("submitted_date"))
    .withColumn("resolved_date",            F.to_date("resolved_date"))
    .withColumn("requested_adjustment_pct", F.col("requested_adjustment_pct").cast("double"))
    .withColumn("synthetic",                F.col("synthetic").cast("boolean"))
    .dropna(subset=["appeal_id", "parcel_id", "reason_code", "narrative"])
    .dropDuplicates(["appeal_id"])
)
(fact_appeal.write.format("delta").mode("overwrite")
    .option("overwriteSchema", "true").saveAsTable("fact_appeal"))
print("fact_appeal:", fact_appeal.count(), "rows")
    ⓘ
    Ingestion (this typed fact_appeal) belongs to Goal 2. Goal 3 adds the AI signal columns and writes fact_appeal_ai.

Validate Silver

Confirm the conformed model joins end to end on the shared keys:

PySpark 
display(spark.sql("""
    SELECT n.neighborhood_name,
           COUNT(DISTINCT p.parcel_id)   AS parcels,
           ROUND(AVG(a.assessed_value))  AS avg_assessed_value,
           COUNT(i.inspection_id)         AS inspections
    FROM dim_parcel p
    JOIN dim_neighborhood n ON n.neighborhood_id = p.neighborhood_id
    LEFT JOIN fact_assessment a ON a.parcel_id = p.parcel_id
    LEFT JOIN fact_inspection  i ON i.parcel_id = p.parcel_id
    GROUP BY n.neighborhood_name
    ORDER BY avg_assessed_value DESC
"""))

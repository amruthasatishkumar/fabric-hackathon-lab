Build the Silver Layer

Bronze holds the raw source shapes; Silver makes them analytics-ready. Three notebooks transform the mirrored SQL tables into typed dimensions and facts, flatten the Cosmos property documents, explode the nested inspection arrays, and ingest the ADLS appeals - writing managed Delta into a dedicated SilverLakehouse.

Learning Objectives

  • Create a SilverLakehouse and read the Bronze mirrors and shortcut cross-Lakehouse.
  • Transform casing and types for the shared keys (parcelId, neighborhoodId, taxYear, propertyClassCode).
  • Re-derive assessed_value (land + improvement) that mirroring may omit.
  • Flatten Cosmos property documents (including longitude/latitude) and explode the inspections[] array.
  • Ingest the ADLS appeals into a typed fact_appeal (AI enrichment follows in Goal 3).

Set Up the Silver Lakehouse & Notebooks

  1. Create SilverLakehouse with schemas enabled

    Click + New item → Lakehouse → name it SilverLakehouse and enable Lakehouse schemas so tables land in the dbo schema.

  2. Import the three Silver notebooks

    Import 1 - SQL Assessment to Silver, 2 - Cosmos Property Profiles to Silver, and 3 - ADLS Appeals to Silver and AI. Each notebook exposes logical Fabric item names in a parameter cell near the top - set them to the names you recorded in Goal 1. Attach SilverLakehouse as the default and add BronzeLakehouse as a source. In this goal you run notebook 3's ingestion cells only; its AI cells run in Goal 3.

Notebook 1 - SQL Assessment to Silver

  1. Transform every mirrored SQL table into Silver

    Snake-case every column, trim strings, enforce the business keys, and write one managed Delta table per source. The Assessment table re-derives assessed_value (mirroring may drop the computed column), and TaxRate becomes fact_tax_rate keeping its municipal_rate, regional_rate, and education_rate components (Gold combines them):

    Configure cell 
    %%configure -f
{
  "defaultLakehouse": { "name": "SilverLakehouse" }
}
    PySpark 
    sql_mirror_item = "Property Assessment SQL Mirror"
source_schema = "dbo"
    PySpark 
    import re
import requests
from pyspark.sql import functions as F
from pyspark.sql.types import StringType

import notebookutils
workspace_id = notebookutils.runtime.context["currentWorkspaceId"]

def resolve_item_id(display_name, item_type):
    token = notebookutils.credentials.getToken("pbi")
    url = f"https://api.fabric.microsoft.com/v1/workspaces/{workspace_id}/items?type={item_type}"
    response = requests.get(url, headers={"Authorization": f"Bearer {token}"}, timeout=60)
    response.raise_for_status()
    matches = [item for item in response.json()["value"] if item["displayName"] == display_name]
    if len(matches) != 1:
        raise ValueError(f"Expected one {item_type} named '{display_name}', found {len(matches)}")
    return matches[0]["id"]

def snake_case(name):
    name = re.sub(r"(?<=[a-z0-9])(?=[A-Z])", "_", name)
    return name.replace(" ", "_").lower()

mirror_id = resolve_item_id(sql_mirror_item, "MirroredDatabase")
spark.sql("CREATE SCHEMA IF NOT EXISTS dbo")
print(f"Resolved SQL mirror: {mirror_id}")
    PySpark 
    table_map = {
    "Jurisdiction": ("dim_jurisdiction", ["JurisdictionId"]),
    "Neighborhood": ("dim_neighborhood", ["NeighborhoodId"]),
    "PropertyClass": ("dim_property_class", ["PropertyClassCode"]),
    "Parcel": ("dim_parcel", ["ParcelId"]),
    "Building": ("dim_building", ["BuildingId"]),
    "Assessment": ("fact_assessment", ["ParcelId", "TaxYear"]),
    "Sale": ("fact_sale", ["SaleId"]),
    "TaxRate": ("fact_tax_rate", ["TaxYear", "PropertyClassCode"]),
}

for source_table, (target_table, source_keys) in table_map.items():
    path = (
        f"abfss://{workspace_id}@onelake.dfs.fabric.microsoft.com/"
        f"{mirror_id}/Tables/{source_schema}/{source_table}"
    )
    frame = spark.read.format("delta").load(path)
    for column in frame.columns:
        frame = frame.withColumnRenamed(column, snake_case(column))
    for field in frame.schema.fields:
        if isinstance(field.dataType, StringType):
            frame = frame.withColumn(field.name, F.trim(F.col(field.name)))
    if target_table == "fact_assessment":
        frame = frame.withColumn("assessed_value", F.col("land_value") + F.col("improvement_value"))
    keys = [snake_case(key) for key in source_keys]
    frame = frame.dropna(subset=keys).dropDuplicates(keys)
    (frame.write.format("delta").mode("overwrite")
        .option("overwriteSchema", "true")
        .saveAsTable(f"dbo.{target_table}"))
    print(f"{target_table}: {frame.count()} rows")
    ⓘ
    Keeping the three rate components in fact_tax_rate (rather than a pre-summed rate) lets Gold compute combined_rate and estimated_tax transparently.

Notebook 2 - Cosmos Property Profiles to Silver (Copilot-guided)

This is a guided discovery notebook - it ships as prompts, not finished code. Paste each prompt into the notebook's Copilot, place the generated code in the empty cell below it, run it, and check the verification note. Steps 1-3 attach the Silver Lakehouse, set the mirror parameters, and read the mirrored Cosmos table into raw.

  1. Step 4 - Flatten one property profile per parcel

    Paste this prompt into Copilot. The GeoJSON coordinates array is longitude first, then latitude:

    Copilot prompt 
    From the raw Cosmos DataFrame, create a DataFrame named profiles with one row per parcel. Select and rename these fields: parcelId to parcel_id; documentType to document_type; synthetic cast to boolean; neighborhoodId and neighborhoodName to snake_case; jurisdiction.countryCode, regionCode, and currencyCode to country_code, region_code, and currency_code; GeoJSON location.coordinates element 0 cast to double as longitude and element 1 cast to double as latitude; site.syntheticAddress, propertyClassCode, zoningCode, and lotAreaSquareMetres to snake_case with the area cast to double; building.type, yearBuilt, floorAreaSquareMetres, and condition to building_type, year_built, floor_area_square_metres, and building_condition with numeric casts; and currentAssessment.taxYear, assessedValue, and confidenceScore to current_tax_year, current_assessed_value, and confidence_score with numeric casts. Drop rows with null parcel_id or neighborhood_id and de-duplicate by parcel_id. Write profiles in overwrite mode with overwriteSchema true as the managed Delta table dbo.property_profile.

  2. Step 5 - Explode inspection history

    Paste this prompt into Copilot. explode_outer keeps parcels that have no inspections, and we retain the observations array:

    Copilot prompt 
    From raw, create an inspections DataFrame by selecting parcelId as parcel_id and using explode_outer on the inspections array into a struct named inspection. Flatten the struct into inspection_id, inspection_date cast to date, inspection_type, condition, observations, and follow_up_required cast to boolean. Drop rows with null parcel_id or inspection_id and de-duplicate by inspection_id. Write the result in overwrite mode with overwriteSchema true as the managed Delta table dbo.fact_inspection.

Notebook 3 - ADLS Appeals to Silver (ingestion)

  1. Transform the appeals into fact_appeal

    Import 3 - ADLS Appeals to Silver and AI and run its ingestion cells now - the AI cells run in Goal 3. It resolves the Bronze Lakehouse, reads the appeal Parquet through the appeals shortcut, snake-cases and types the columns, keeps the raw narrative and ground_truth_sentiment, and writes dbo.fact_appeal:

    Configure cell 
    %%configure -f
{
  "defaultLakehouse": { "name": "SilverLakehouse" }
}
    PySpark 
    bronze_lakehouse_item = "BronzeLakehouse"
appeal_file_path = "Files/appeals/assessment_appeals.parquet"
    PySpark 
    import re
import requests
from pyspark.sql import functions as F

import notebookutils
workspace_id = notebookutils.runtime.context["currentWorkspaceId"]

def resolve_item_id(display_name, item_type):
    token = notebookutils.credentials.getToken("pbi")
    url = f"https://api.fabric.microsoft.com/v1/workspaces/{workspace_id}/items?type={item_type}"
    response = requests.get(url, headers={"Authorization": f"Bearer {token}"}, timeout=60)
    response.raise_for_status()
    matches = [item for item in response.json()["value"] if item["displayName"] == display_name]
    if len(matches) != 1:
        raise ValueError(f"Expected one {item_type} named '{display_name}', found {len(matches)}")
    return matches[0]["id"]

def snake_case(name):
    return re.sub(r"(?<=[a-z0-9])(?=[A-Z])", "_", name).lower()

bronze_id = resolve_item_id(bronze_lakehouse_item, "Lakehouse")
source_path = f"abfss://{workspace_id}@onelake.dfs.fabric.microsoft.com/{bronze_id}/{appeal_file_path}"
raw = spark.read.parquet(source_path)
for column in raw.columns:
    raw = raw.withColumnRenamed(column, snake_case(column))
    PySpark 
    appeals = (raw
    .withColumn("tax_year", F.col("tax_year").cast("int"))
    .withColumn("submitted_date", F.to_date("submitted_date"))
    .withColumn("resolved_date", F.to_date("resolved_date"))
    .withColumn("requested_adjustment_pct", F.col("requested_adjustment_pct").cast("double"))
    .withColumn("synthetic", F.col("synthetic").cast("boolean"))
    .dropna(subset=["appeal_id", "parcel_id", "reason_code", "narrative"])
    .dropDuplicates(["appeal_id"]))

assert appeals.filter(F.col("synthetic") != True).count() == 0
assert appeals.filter(F.length(F.trim("narrative")) == 0).count() == 0
(appeals.write.format("delta").mode("overwrite")
    .option("overwriteSchema", "true").saveAsTable("dbo.fact_appeal"))
print(f"Conformed appeals: {appeals.count()}")
    ⓘ
    Ingestion (this typed fact_appeal) belongs to Goal 2. Goal 3 adds the AI signal columns and writes fact_appeal_ai.

Validate Silver

Confirm the transformed model joins end to end on the shared keys:

PySpark 
display(spark.sql("""
    SELECT n.neighborhood_name,
           COUNT(DISTINCT p.parcel_id)   AS parcels,
           ROUND(AVG(a.assessed_value))  AS avg_assessed_value,
           COUNT(i.inspection_id)         AS inspections
    FROM dim_parcel p
    JOIN dim_neighborhood n ON n.neighborhood_id = p.neighborhood_id
    LEFT JOIN fact_assessment a ON a.parcel_id = p.parcel_id
    LEFT JOIN fact_inspection  i ON i.parcel_id = p.parcel_id
    GROUP BY n.neighborhood_name
    ORDER BY avg_assessed_value DESC
"""))

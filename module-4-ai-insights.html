AI on Appeal Narratives

Assessment appeals arrive as free text. Starting from the fact_appeal you ingested in Goal 2, this module uses Fabric's ai.* functions to derive a sentiment label, a concise summary, a normalized reason classification, and a follow-up signal - keeping the original narrative and storing AI output in new columns. You then evaluate the results against a supplied ground-truth label.

Learning Objectives

  • Start from dbo.fact_appeal (ingested in Goal 2) and run notebook 3's AI cells.
  • Derive sentiment, summary, reason classification, and a follow-up signal with the ai.* functions.
  • Evaluate AI sentiment against ground_truth_sentiment (accuracy, confusion matrix, reason agreement).
  • Apply responsible-AI checks and preserve lineage to the source appeal.

Step 1 - Start from fact_appeal

You already created dbo.fact_appeal in Goal 2 with notebook 3's ingestion cells (the transformed appeals with the raw narrative and the ground_truth_sentiment label). Continue in 3 - ADLS Appeals to Silver and AI at the AI enrichment section - the following cell requires Fabric AI functions to be enabled.

Step 2 - Enrich with the ai.* Functions

Apply the AI functions over the appeal narrative and add the signals in new columns. Keep the original narrative:

PySpark 
import pandas as pd
import synapse.ml.aifunc as aifunc

pdf = appeals.toPandas()
text = pdf["narrative"].astype(str)
pdf["ai_sentiment"] = text.ai.analyze_sentiment()
pdf["ai_summary"] = text.ai.summarize()
pdf["ai_reason_code"] = text.ai.classify(
    "COMPARABLE_SALES", "PROPERTY_CONDITION", "DATA_CORRECTION",
    "CLASSIFICATION", "RENOVATION_TIMING", "INFORMATION_REQUEST"
)
pdf["ai_follow_up"] = text.ai.classify("urgent_follow_up", "standard_review")
pdf["enriched_at_utc"] = pd.Timestamp.utcnow().isoformat()

enriched = spark.createDataFrame(pdf)
(enriched.write.format("delta").mode("overwrite")
    .option("overwriteSchema", "true").saveAsTable("dbo.fact_appeal_ai"))
✓
Start with the supplied classification taxonomy, then document any changes: COMPARABLE_SALES, PROPERTY_CONDITION, DATA_CORRECTION, CLASSIFICATION, RENOVATION_TIMING, INFORMATION_REQUEST. The follow-up classifier returns urgent_follow_up or standard_review; the urgent_follow_up boolean is derived later in the Gold appeal mart.

Step 3 - Evaluate Against Ground Truth

The seed data includes ground_truth_sentiment for technical evaluation. Compute enrichment success, sentiment accuracy, reason-code agreement, and a confusion matrix:

PySpark 
evaluation = (spark.table("dbo.fact_appeal_ai")
    .withColumn("enrichment_success", F.col("ai_sentiment").isNotNull() & F.col("ai_summary").isNotNull() & F.col("ai_reason_code").isNotNull())
    .withColumn("sentiment_match", F.coalesce(F.lower("ai_sentiment") == F.lower("ground_truth_sentiment"), F.lit(False)))
    .withColumn("reason_match", F.coalesce(F.upper("ai_reason_code") == F.upper("reason_code"), F.lit(False))))

display(evaluation.groupBy("ground_truth_sentiment", "ai_sentiment").count().orderBy("ground_truth_sentiment", "ai_sentiment"))
display(evaluation.agg(
    F.count("*").alias("records"),
    F.avg(F.col("sentiment_match").cast("double")).alias("sentiment_accuracy"),
    F.avg(F.col("reason_match").cast("double")).alias("reason_code_accuracy"),
    (F.lit(1.0) - F.avg(F.col("enrichment_success").cast("double"))).alias("enrichment_failure_rate"),
))
ⓘ
Review examples where the model disagrees with the label. A useful solution does not hide uncertain or failed enrichment - surface the failure rate and the mismatches.

Responsible AI Checks

⚠
  • Do not infer protected or personal characteristics.
  • Do not use sentiment as an automatic approval or rejection rule - it is decision support only.
  • Preserve lineage to the source appeal (appeal_id).
  • Record function metadata and an enrichment timestamp (enriched_at_utc).

A governed, evaluated appeal-intelligence table that turns free-text narratives into structured signals with lineage and quality metrics. The Gold marts fold these signals in next.

What is the Sudsberry lab?

You'll build an end-to-end analytics and AI solution for the fictional municipality of Sudsberry. It combines property valuation records, flexible inspection documents, and assessment appeal narratives into one governed Fabric workspace. All records are synthetic and do not represent real people, addresses, parcels, assessments, sales, or tax policy.

🏠

Property valuation

Parcels, buildings, assessments, sales, tax rates, and reference data live in an Azure SQL relational system of record, mirrored into Fabric without moving data.

📋

Inspection documents

Flexible property profiles with nested inspection history live in Cosmos DB as JSON documents, mirrored into Fabric and flattened in Silver.

📝

Appeal narratives

Free-text assessment appeals land in ADLS Gen2 as JSON/Parquet, reached through a OneLake shortcut and enriched with Fabric AI functions.

Across the lab, you'll connect three sources into a Bronze Lakehouse, transform them into conformed Silver dimensions and facts, apply AI to appeal narratives, and build Gold marts with a Direct Lake semantic model, a report, a Fabric ontology, and an ontology-grounded Data Agent.

Setup

Connect the Sources (Bronze)

Build the Bronze layer without moving data - mirror Azure SQL (parcels, assessments, sales) and Cosmos DB (property profiles), and shortcut the ADLS appeal files into one BronzeLakehouse.

Goal 1 · Bronze

Build the Silver Layer

Conform the mirrored SQL tables into typed dimensions and facts, flatten the Cosmos property documents, and explode the nested inspection arrays into a SilverLakehouse with two notebooks.

Goal 2 · Silver

AI on Appeal Narratives

Load the ADLS appeals, then use Fabric's built-in ai.* functions to derive sentiment, summaries, a reason classification, and a follow-up signal - and evaluate the results against a ground-truth label.

Goal 3 · AI

Gold Business Marts

Build joined analytical marts in the GoldLakehouse - property assessment, comparable sales, appeal intelligence, and neighbourhood equity - ready for a semantic model and a data agent.

Goal 4 · Gold

Direct Lake + Power BI

Build a Direct Lake star-schema semantic model on the Gold marts and ship a property-assessment report - no import refresh, no DirectQuery latency.

Goal 4 · Gold

Fabric Ontology

Build a governed semantic graph (PropertyAssessmentOntology) over your Gold marts. Define Property, Neighborhood, ComparableSale, and Appeal entities and their relationships so the agent reasons about concepts, not table joins.

Goal 4 · Gold

Build a Fabric Data Agent

Ground a property-assessment Data Agent on the PropertyAssessmentOntology and validate it in the Fabric agent canvas with relationship-aware questions about valuations, sales, and appeals.

Goal 4 · Gold
